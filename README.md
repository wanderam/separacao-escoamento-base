# Separação escoamento de base (Sepbaseflow)

Procedimento para separação da vazão em escoamento superficial e de base. A série de escoamento de base foi estimada a partir de dados observados de vazão da bacia hidroráfica do rio Corumbataí.

* Hydrograph-py [(Terink 2019).](https://app.readthedocs.org/projects/hydrograph-py/downloads/pdf/latest/)
